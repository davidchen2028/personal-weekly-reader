# 个人周刊阅读器 Android 2.0

适用：vivo X Fold 系列及 Android 8.0 以上设备。包名沿用 local.caixin.reader，使用原签名，可覆盖安装 1.0.1。

## 四刊与登录
支持财新、经济观察报、财经杂志、第一财经。财经增刊、第一财经单行本同时纳入目录。各刊书架可按年份选择，目录展示所有栏目。
在顶部选择刊物，进入设置选择“登录当前刊物”，在官方网站完成登录后点击底部“返回阅读”。第一财经在返回时读取本站必要的 Authorization 字段；Cookie 和令牌只保存在应用私有空间。
手机与电脑、手机 Chrome 的登录相互独立，不安装 Chrome 扩展。网站验证码、订阅范围、设备限制以官网为准。原文入口保留，不改变官网权限判断。

## 阅读
单栏、双栏、双屏翻页三种模式；外屏窄窗口显示单页，内屏并排双页。支持上一页、下一页以及连接键盘后的 PageUp / PageDown。
支持宽度切换、字号、15 种配色、图片放大、原文、回书架、本文缓存清除。
配置变化保留 Activity 与 WebView，连续阅读保留段落位置，分页模式重新排版。实际屏幕宽度决定布局，而非硬编码设备型号。

## 目录与缓存
书架与期刊目录落盘，本地优先。书架显示缓存后异步检查官网；失败仍显示本地内容。首次无缓存需联网扫描历史目录。
“缓存最近100期”只作用于所选刊物，包括增刊或单行本。下载完整正文和全部配图后才写入成功的正文文件；下次发现已有文件直接复用，不请求官网复核正文。
每刊完成后设置独立的六小时检查时间。应用运行且处于非文章页面时检查到期任务。打开文章、切换刊物会中止当前后台操作，后续通过本地缓存跳过已完成内容。
关闭应用、系统回收、强制停止后不会保证继续执行；下次打开在调度检查时续传。没有添加前台服务或要求系统后台常驻权限。
缓存长期保留，超过最近100期的旧文件不会自动删除；设置显示总占用并支持清除。登录新会话分开保存缓存，退出登录会清除四刊会话和本机内容。

## 验证范围
- 正式 APK 编译、原签名 v2/v3 验证通过。
- 浏览器自动化：内外屏段落连续、字号、15配色选项、双屏翻页、PageDown。
- 解析测试：财新分页与结束图标、首图/正文配图；第一财经题图和授权；经济观察报全部版面、重复文章ID；财经正文配图。
- Android 35 模拟器实际运行：四刊书架发现（财新826、经济观察报1168、财经442、第一财经635），财经目录33篇，第一财经目录34篇。
- 测试环境未导入用户付费登录，不宣称四刊付费全文及100期批量下载已完成真机验收。需要在手机安装并登录后验证；未在实体 vivo 设备上测试系统后台策略。

## 安装
将 android/dist/weekly-fold-reader-2.0.0.apk 传到手机并打开，允许该文件来源安装应用。建议直接覆盖安装，不要先卸载旧版。
