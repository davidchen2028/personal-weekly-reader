# 财新周刊 · 本地阅读器 v2

本机地址：http://127.0.0.1:4317

## 启动

需要 Node.js 22+ 和 Google Chrome。双击 `启动阅读器.command`；或在本目录执行 `npm install`、`npm start`。关闭终端会停止服务。

## 连接日常 Chrome

1. 在日常使用的 Chrome 登录财新。
2. 打开 `chrome://extensions`，启用开发者模式，选择「加载已解压的扩展程序」，选择项目的 `extension` 目录。
3. 在阅读器点击连接入口，生成一次性配对码。在扩展弹窗输入配对码，点击「配对并同步」。后续会自动同步财新 Cookie，也可手动立即同步。
4. 扩展更新后，在扩展管理页重新加载。配对凭据保留；权限变更时需接受新权限。

扩展仅申请财新域、本机服务、Cookie、存储和定时同步权限。财新域同时声明 HTTP/HTTPS，是因为 Chrome 根据 Cookie 的 Secure 属性检查站点权限；只声明 HTTPS 会遗漏非 Secure Cookie。文章仍通过 HTTPS 获取。不会读取其他网站 Cookie，不接管日常 Chrome 的用户数据目录。

「会话已同步」只代表收到 Cookie，文章权限以财新实际返回内容为准。如仍显示订阅提示，请在日常 Chrome 确认本文可读并重新同步。也可通过本地弹窗导入 Cookie 数组。

## 阅读与缓存

- 书架按年份列出周刊，点击封面进入宽屏目录，再进入文章。
- 后台优先尝试 HTTP；需要网站脚本时使用无头 Chrome，自动点击原文「余下全文」，必要时沿本文分页补齐。日常阅读不打开可见窗口。
- 按原文顺序保留图片、图注和署名，支持放大、失败重试。只有核验结束或全部章节后才显示全文完成；否则保留部分内容并明确标注。
- 支持字号、纸白/护眼/夜间配色和双栏排版，窄屏自动单栏。双栏为连续排版，不模拟翻页。
- 缓存实际打开的正文和已加载图片，默认 30 天、总容量 1 GB。支持刷新本文、清除本文及全部缓存。会话变化时保守隔离缓存，可能需要重新读取。
- 断开连接会撤销配对并删除阅读器会话，不修改日常 Chrome 的登录。清理内容文件使用清除全部缓存。

## 数据与边界

会话和缓存位于 `~/Library/Application Support/CaixinReader/v2`，会话文件权限为 600，目录为 700。Cookie 不进入项目、日志或阅读器前端存储。服务只监听 `127.0.0.1`，验证 Host、Origin、配对令牌和图片来源。网络请求仍发送至财新以获取用户已获授权的内容。

不绕过付费墙；全部缓存仅保存当前账号可读取的内容。视频、音频和互动内容请查看原文。页面结构或网站鉴权变化可能造成读取失败；无头浏览器不保证所有文章均比原网站更快。

旧版独立登录目录 `~/Library/Application Support/CaixinReader/browser` 不再使用，升级不会自动删除它。

## 全部缓存与每 6 小时同步

顶部「全部缓存」启动后台任务，逐一读取周刊首页全部年份（包括隐藏的“加载更多”条目）、每期所有栏目和文章，并缓存封面、可读取的正文与文中配图。正文分页继续使用原有“余下全文”提取流程。进度面板显示已完成期数、文章、配图、失败项目与下一次检查时间；多次点击不会重复启动任务。

正常 `npm start` 启动后首次自动执行；未连接账号时等待同步。之后每 6 小时重新检查书架，新刊会自动加入。已有完整正文和图片跳过下载，失败项目下轮重试；读取受限或返回 401/403/429 时停止本轮并提示处理。没有完整性证据的正文也会保存当前可见内容和配图，但保持“完整性待确认／正文未取齐”标识，不计为完整成功，下轮继续重试。

长期存档位于 `~/Library/Application Support/CaixinReader/v2/library`，与原有 30 天、1 GB 临时缓存分开，**不自动按时间或容量淘汰**，大量历史杂志会持续占用磁盘。设置中可查看空间占用；进度面板可暂停（同时停用自动检查），或清除长期存档。清除后保留公开目录索引；点击「全部缓存」重新下载并恢复定时检查。

正常退出后未完成任务会在下次启动恢复，已写入存档无需重新下载。服务关闭或 Mac 休眠期间不会运行，重新运行后补做已到期的检查。不需要保持网页标签打开，但启动服务的终端需保持运行。可识别财新账号 ID 时长期正文按账号隔离；缺少账号 ID 时保守按同步会话隔离。公开封面和目录可共用。

离线时书架可回退至最近同步目录，已存档文章和图片从本机读取。自动遍历范围为官网周刊首页列出的期刊和每期目录提供的文章，不遍历全站推荐链接。后台下载是渐进任务，看到“全部缓存中”不等于所有历史文章已下载完成。

## 财新／经济观察报双刊（2026-09-27）

页头刊物选择器切换书架、年份、目录及连接状态。当前刊物的「全部缓存／暂停／清除」只影响该刊；两刊首次连接后各自每6小时检查。文章仍在新标签页打开。经济观察报只下载正文与文章配图，PDF／整版报纸请使用原站入口。

### 扩展升级

在 `chrome://extensions` 重新加载项目的 `extension` 文件夹，确认版本为 **3.0.0**。扩展选择「经济观察报」，点击「立即同步登录状态」，按 Chrome 提示允许经济观察报站点权限。先在同一 Chrome 正常登录并确认电子报可读。可复用原有本机配对；只有显示配对失效时才重新生成配对码。

扩展只在用户授权后读取 eeo.com.cn 域的 Cookie，财新和经济观察报分别同步。不修改 Chrome 的登录状态，也不会将两个站点 Cookie 放入同一个浏览器上下文。扩展内断开当前刊物后会停止该刊定时同步，手动同步可恢复。

### 经济观察报发现与缓存

历史期刊沿官网真实“下一页”发现，保存扫描游标。年份来自发行日期，首次发现可能需要等待；完成后通常只检查前部已知分页。书架「重新扫描目录」可重新扫描完整历史，发现旧页面补录。

期刊目录按版次展示，一次整期响应拆为按文章ID的阅读条目，避免对每篇重复请求同一期。显式登录／购买提示优先处理；不能仅凭匿名接口的 HTTP200 判断订阅权限。结构未核实的正文保持“待确认”。

每篇长期存档在原缓存目录新增 `manifest.json`，记录正文和全部图片的大小、校验值及完成时间。完整命中时直接跳过文章／配图请求；缺图只补图。旧财新存档首次检查时渐进生成记录，不移动原文件。完整性未核实或资源未落盘不会标记 complete。两个刊物共用最多2个正文读取槽，排队时前台优先。

经济观察报数据位于 `~/Library/Application Support/CaixinReader/v2/providers/eeo`；财新目录保持原位。当前经济观察报缺少已验证的稳定账号ID，因此保守按会话范围隔离；Cookie发生变化可能需要重新核对／下载，不能声称跨任意登录变更都可直接复用付费存档。

### PC 缓存策略（2026-09-28）

取消首次连接、重启和每六小时自动下载。点击“缓存最近100期”才启动当前刊物的下载；首页已有的缓存优先展示及异步更新列表保留，不自动下载正文。

同刊目录、正文和图片的 HTTP 请求串行执行，完成后至少间隔 2 秒。普通失败后下一次请求等待 4、8、16、32、60 秒（上限），成功后恢复 2 秒。空响应、空正文、403、429 或订阅限制暂停该刊，显示原因，确认官网恢复后手动继续，不定时重试。其他刊物独立运行。

已完整落盘的文章及配图直接跳过，不到官网复核；缺失项才补充。空正文拒绝写入缓存，保留既有内容。已保存的历史存档不会因为本次策略变更被删除。
