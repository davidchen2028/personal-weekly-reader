# 四刊阅读器实施与验证

2026-09-27

## 已实现

- Chrome扩展4.0.0：一个配对码、一键同步全部、分刊重试和断开。首次配对或一键同步时按需申请四刊站点权限。一个失败不阻断其他刊；重新配对不清空原刊会话。
- 每刊诊断卡：最近尝试时间、最近有效凭证送达时间、最近同步时间、Cookie检查时间/数量、本机最近收到数量、错误原因；第一财经另显示令牌是否读取。状态仅表示凭证传输，不伪称订阅权益通过。
- 本机账号界面显示四刊最近接收时间、Cookie数量与令牌状态；详细错误查看扩展。凭证值不展示。
- 第一财经：杂志及单行本、年份、类型筛选、目录全部板块、授权全文API、有序正文和配图、独立缓存与六小时调度。无订阅权限不标全文。
- 目录页恢复统一导航头并隐藏缓存进度；文章页顶部固定返回目录、宽度、阅读设置和配色；动态高度避让，取消底部浮动栏。

## 实测证据

公开列表发现635项，其中20项单行本，年份2008—2026。样例649目录返回5板块、34篇；官网期刊元数据标称33篇，保留实际34篇并提示差异，绝不截断。未登录34768文章正确识别为受限试读。

45项自动测试通过，另扩充四刊API令牌/状态隔离回归。浏览器脚本 `node scripts/test-four-ui.mjs` 验证真实书架及目录、四刊连接汇总、顶部固定栏、宽屏、直接配色和移动窗口无横向溢出；文章布局用浏览器内夹具，不存入本机订阅缓存，不作为真实付费验收。

## 需用户完成的一次操作

Chrome扩展页重新加载本项目extension目录，确认4.0.0。保持一个已经登录的https://www.cbnweek.com/普通标签页，点击“立即同步全部”并授权新增站点。已有配对直接复用；仅首次安装需要配对码。

第一财经仅定向读取官网标签页localStorage.Authorization一个字段，不复制userInfo。当前采用scripting定向读取，无需发送账号密码。每分钟自动检查令牌需保留官网标签页；无标签页会明确报错，并保留最近成功记录，不假称成功。

## 尚未验证与边界

截至本次记录，尚未收到第一财经真实令牌，不能声称已通过付费全文末段及全部配图验收。单行本可能需单独购买，按官网返回权限处理。

目前使用官网公开脚本对应的正常API请求格式；请求格式变化时明确失败，不猜测替代签名。授权响应包含完整正文，直接呈现全部内容，等效于解除前端视觉折叠；不从无权限响应拼接或恢复全文。目录缺少条目或正文篇幅不足返回待核验。本次未实现未知页面结构的通用浏览器回退。

尚未核实第一财经稳定账号ID，存档暂按会话隔离，令牌变化可能导致重新下载。保持保守隔离，不跨账号猜测复用。PDF、ZIP、音频和Android升级不在本轮。

## 4.0.1 恢复连接修复

实测本机第一财经处于 disabled 状态，已读到的凭证因此被服务拒绝。修复扩展并发合并：手动恢复遇到在途后台同步时等待其结束，再发 resume=true，而不是复用不带恢复标志的旧任务。断开操作也等待在途同步结束，防止旧任务覆盖断开状态。新增定向本机恢复接口（仍受原有Host/Origin校验），不会恢复其他刊物或改变配对。

本次已恢复用户的第一财经连接，并由扩展自动收到6项Cookie及令牌；官网返回示例34768 is_jurisdiction=true。真实全文图片使用imgcdn.yicai.com，补充该明确官方资源域至适配器白名单；授权令牌仍仅发送api.cbnweek.com，不发送图片域。
