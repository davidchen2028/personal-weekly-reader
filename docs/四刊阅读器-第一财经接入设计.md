# 个人周刊阅读器：第一财经接入设计

2026-09-27 · 讨论确认版 · 本轮仅设计，未修改业务代码

## 一、已确认需求

新增刊物“第一财经”，内部标识 `cbnweek`，与财新、经济观察报、财经杂志隔离。杂志及单行本均纳入，支持年份下拉与“全部／杂志／单行本”筛选。延续当前沉浸阅读、宽屏开关、新标签页文章、主题和字号设置。

沿用 Chrome 同步登录态、本机缓存全文与全部配图、首次同步及每6小时检查。“全部缓存”覆盖当前刊物全部已发现年份及两种出版物，不受当前筛选限制；正文及必要配图成功后记完成，下次跳过，缺图补齐。

用户确认：同一个 Chrome 中登录后可以阅读示例全文；允许扩展仅额外读取 cbnweek.com 的 localStorage.Authorization 必要登录字段。账号信息优先通过官网已登录接口核验，不读取完整 localStorage 或 userInfo。

PDF、ZIP整刊包、音频不批量下载，只在官网实际提供有效入口时保留原站链接；本轮不改 Android。

## 阅读器统一布局（本轮补充确认）

以下布局调整适用于全部刊物，不仅是第一财经：

- 周刊目录页恢复统一导航头，与首页保持相同的刊物名称、“个人周刊阅读器”、书架入口、Chrome同步入口及刊物选择器位置。刊物选择器仍位于Chrome同步右侧。目录页不展示自动缓存进度面板，保留清晰的返回书架入口。
- 文章详情页取消底部浮动栏，改为横跨阅读区域的顶部固定工具栏，按顺序提供“返回本期目录”“标准／宽屏切换”“阅读设置”“护眼配色”。从无目录上下文的文章入口进入时，返回项显示“返回书架”。
- 护眼配色作为独立可见控件，提供纸白、护眼、夜间；字号、单双栏、刷新全文、清除本文缓存和原站入口收纳在阅读设置中。
- 顶部工具栏固定于视口顶部，随正文滚动持续可用；文章页不叠加完整首页导航头或自动缓存面板。
- 正文顶部预留工具栏实际高度，包括窄窗口换行后的高度；锚点滚动同样避让。宽屏、主题与字号偏好继续记忆，切换不改变正文内容。
- 小屏工具栏可换行或紧凑排列，不产生横向溢出，不遮挡标题及设置弹层。设置弹层支持键盘操作和关闭。

验收增加：四刊首页/目录页导航一致；文章页顶部工具栏滚动固定；顶部标题及段落无遮挡；返回目录上下文正确；护眼配色直接可调；底部不再出现浮动工具栏。

## 二、公开调研事实及边界

来源：

- 列表：https://www.cbnweek.com/read
- 目录：https://www.cbnweek.com/magalog/649
- 文章：https://www.cbnweek.com/article_detail/34768
- 官网加载的前端脚本：`https://www.cbnweek.com/static/js/app.3484347ad319619555ec.js`（构建文件名可能变化，不硬编码）

已通过无头 Chrome 查看页面与官网正常网络请求：

| 项目 | 观察结果 |
| --- | --- |
| 年份 | `/v5/magazines/years`，杂志2008—2026，单行本2016—2026；运行时读取，不写死 |
| 年份列表 | `https://api.cbnweek.com/v5/magazines?year=2026&type=`，按月份分组，混合不同出版物 |
| 期刊信息 | `/v5/magazines/649`；列表元数据中的内部ID649、总期号628不可混用，articles_count为33 |
| 目录 | `/v5/magazines/649/articles`；页面有多个“查看更多”板块 |

| 登录 | 官网脚本将令牌存入localStorage.Authorization，退出时清除；请求存在X-Signature机制 |
| 阅读展开 | 官网代码在is_jurisdiction满足条件时显示“点击查看更多内容，或下载客户端”，通过seeMore控制展开 |
| 封面 | 已观察到imgcdn.cbnweek.com资源域 |

目录第一次访问看到5个展开入口，但另一次操作遇到数据尚未加载的占位板块，说明不能“找到一个按钮就视为页面加载完成”。33篇来自期刊元数据，不是已完成逐篇目录验收。实际完整目录、登录请求头、正文展开后的全部图文、账号身份字段需在编码阶段对照真实已登录页面验证。

## 三、登录态同步设计

扩展升级，新增cbnweek.com的HTTP与HTTPS可选域权限，兼容Secure及非Secure Cookie；明确区分已配对、凭证已同步、官网已核实登录、当前文章无权益四种状态。

第一财经使用Cookie加Authorization令牌，不能以Cookie数量判断成功：有有效令牌而Cookie为0可进入官网验证；两者都空则提示未连接，并撤销本机旧凭证以防继续使用已退出账号。

建议通过仅匹配 `https://www.cbnweek.com/*` 的内容脚本读取一个固定字段，后台核对消息发送者域名、当前provider及配对状态，再发送到127.0.0.1。不读取任意网站存储、不复制userInfo。首次授权后用户保持一个已登录官网标签页并刷新以启用脚本。页面加载、可见性恢复、storage事件及定时比较触发令牌同步；同标签页登录也要覆盖，不能只依赖storage事件。

Cookie与令牌在服务端同一次会话更新中落盘，避免先发空Cookie再发令牌造成任务反复中止。扩展不在状态页、错误、日志或聊天显示令牌，服务端只保存受限文件，令牌只发送到已核验api.cbnweek.com接口；不附加到图片、统计域和跨域重定向。

账号核验优先使用官网正常调用的 `/v5/users/me`，确认实际返回的稳定账号标识后在本机散列，用于存档归属。令牌刷新不应造成全部重下载；账号切换必须隔离。如接口不能可靠核验身份，保守按会话隔离并明确提示此限制，不猜测账号身份。

## 四、列表和全部目录

列表分别发现杂志、单行本年份及官网真实分页/加载更多机制。保持出版日期与期号原意，按官网显示日期排序；单行本不伪造总期号。

混合列表中杂志和单行本可能有相同数字ID，唯一键为 `provider + publicationType + id`。单行本的真实目录路由必须从官网卡片/请求观察，不能直接套用magalog。

目录优先使用正常登录请求返回的完整结构，保留全部板块、板块顺序与文章顺序。若接口按板块分页或延迟加载，跟随官网真实请求取完每板块；浏览器回退则在数据就绪后逐一点击全部“查看更多”，重新检查是否还有未展开或待加载板块。

结束条件：期刊身份正确；所有已发现板块完成；无未完成分页；目录文章计数与官网可用计数可解释一致。遇空目录、超时、计数差异只标“目录未完成”，不把不完整目录持久化成成功结果。去重按文章身份，保留文章与多个板块/出版物的关联。

## 五、全文与图片

优先HTTP复用已登录会话，使用官网正常请求格式；签名、动态验证无法可靠复用时转无头浏览器正常页面流程，不伪造权益字段。无头浏览器在访问目标origin前注入必要令牌并加载Cookie，完成后核验页面真实权限。

“查看全文”仅在当前账号有阅读权限时展开。检测官网实际文案及控件，展开后等待正文稳定及异步内容完成，必要时滚动触发懒加载；若存在真实同篇分页则完整合并，不能把上一篇/下一篇/推荐文章混入。

完整性条件同时包括：官网明确可读、无试读/购买墙、展开完成、正文非空、篇幅与标称字数无明显差距、分页完成。字数阈值仅作缺失告警，不能单独证明全文。失败返回预览、权限不足或待核验，绝不写完成清单。

正文保留标题、署名、日期、摘要、小标题、段落、所有正文配图及图注，保持顺序。支持src/srcset/懒加载，移除广告、推荐、交互脚本。图片下载白名单基于实际官网资源域增补，未知资源明确报错，不能无声漏图后仍标完整。只下载用户有权正常访问的文章资源。

## 六、架构改动

- 新增 `providers/cbnweek.mjs`：年份/两类列表、目录展开、全文解析、URL校验、身份与权限核验。
- `server.mjs`：第四刊注册与路由；统一provider配置，减少硬编码分支；图片与授权请求分别限制域名。
- `lib/session.mjs`：增加可选令牌与已核实账号身份；兼容原三刊Cookie协议，不改变原数据路径。
- `extension/*`：第四刊、按需权限、限定字段内容脚本、令牌同步与明确状态；旧manifest检查和重载入口保留。
- `public/*`：第四刊品牌、年份及出版物类型筛选，实现上述统一目录导航头与文章顶部固定工具栏。
- 缓存目录：现有数据根目录 `providers/cbnweek/`；内容清单按provider、身份和文章ID隔离。

不迁移或清空现有三刊缓存、配对与登录态。后台任务仍全局限并发、阅读优先；登录失效只暂停第一财经，单篇无权益可记录并继续，429遵守退避。

## 七、缓存与性能

完成清单在正文和所有必要图片原子落盘、校验通过后提交。下次先检查清单再抓文章；目录请求本身可能包含已有文章摘要，不等同于重复下载全文。损坏文件降级重试，中断可恢复，错误项不算成功。

首次自动发现全部目录，之后每6小时检查新刊；长期同步过程中也检查新增期刊。关机、休眠或服务退出期间不执行，恢复后补查。可单独暂停、清除第一财经缓存或断开账号。

记录缓存命中、HTTP、浏览器回退、展开、解析及图像耗时。缓存正文目标1秒内显示；首次浏览器启动和网络请求单独报告，避免承诺所有首次加载均小于1秒。保持宽屏阅读开关及偏好记忆。

## 八、编码顺序与验收

1. 扩展定向同步Authorization，确认真实登录和账号身份；测试零Cookie但有效令牌、退出、令牌更新。
2. 两类出版物/全部年份/分页，验证跨类型ID不冲突。
3. 样例649的全部板块目录与官网逐项对照；以33篇元数据为初始校验参考，差异必须解释。
4. 34768展开后对照正文末段、标称篇幅、图片数量与顺序；至少再抽测一篇多图文章、一个单行本和一个旧刊。
5. 第二次同步跳过完成项，缺图补齐、重启恢复、账号切换隔离、六小时调度。
6. 原三刊回归，以及聚焦阅读、宽屏偏好、新标签页provider保持。
