## 3.1.2：0 项 Cookie 修复

官网匿名响应设置的 laravel_session 未带 Secure；Chromium 的 cookies.getAll 根据 Cookie 的 Secure 属性生成用于权限检查的 URL（cookies_helpers.cc 的 GetURLFromCanonicalCookie / AppendCookieToVectorIfMatchAndHasHostPermission）。3.1.1 仅声明财经 HTTPS 权限，遗漏非 Secure Cookie 所需的 HTTP 域权限。3.1.2 为同一 mycaijing.com 域补齐 HTTP 可选权限，并同步更新弹窗申请和后台检查。网络抓取仍只允许 HTTPS。

空 Cookie 仍传至本机以清除失效会话，但不再显示登录态同步成功；改为提示在同一 Chrome 普通窗口登录。新增权限范围、旧清单重载、正常申请和空同步回归测试，4 项通过。仍需用户重载 3.1.2 并重新授权后进行真实全文验证。
